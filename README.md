Современный минималистичный лендинг для турагентства с плавными анимациями и полной адаптивностью.

## 🎨 Особенности

- ✨ Плавные анимации без перегрузки сайта
- 📱 Полная адаптивность для всех устройств
- 🎯 Минималистичный и строгий дизайн
- ⚡ Оптимизированная производительность
- 🌈 Современные градиенты и эффекты

## 🚀 Как разместить на GitHub Pages

### Вариант 1: Через веб-интерфейс GitHub

1. **Создайте репозиторий на GitHub:**
   - Перейдите на [github.com](https://github.com)
   - Нажмите кнопку "New" (или "+" → "New repository")
   - Назовите репозиторий (например, `wanderlust-landing`)
   - Выберите "Public" или "Private"
   - **НЕ** ставьте галочки на "Add README", "Add .gitignore" и т.д.
   - Нажмите "Create repository"

2. **Загрузите файлы:**
   - На странице созданного репозитория найдите кнопку "uploading an existing file"
   - Перетащите все файлы проекта (index.html, styles.css, script.js, README.md)
   - Нажмите "Commit changes"

3. **Включите GitHub Pages:**
   - Перейдите в Settings репозитория
   - Прокрутите до раздела "Pages" в левом меню
   - В разделе "Source" выберите "Deploy from a branch"
   - Выберите ветку "main" и папку "/ (root)"
   - Нажмите "Save"
   - Через несколько минут ваш сайт будет доступен по адресу: `https://ваш-username.github.io/wanderlust-landing/`

### Вариант 2: Через командную строку (Git)

1. **Инициализируйте Git репозиторий:**
   ```bash
   cd /Users/user/Desktop/portfolio
   git init
   ```

2. **Добавьте все файлы:**
   ```bash
   git add .
   ```

3. **Создайте первый коммит:**
   ```bash
   git commit -m "Initial commit: Wanderlust landing page"
   ```

4. **Создайте репозиторий на GitHub** (через веб-интерфейс, как описано выше)

5. **Подключите удаленный репозиторий:**
   ```bash
   git remote add origin https://github.com/ваш-username/wanderlust-landing.git
   git branch -M main
   git push -u origin main
   ```

6. **Включите GitHub Pages** (как в варианте 1, шаг 3)

## 🎨 Анимации

Все анимации оптимизированы для производительности:
- Плавное появление элементов при скролле
- Плавающие формы в hero-секции
- Анимированные счетчики статистики
- Hover-эффекты на карточках
- Параллакс-эффекты

## 📱 Адаптивность

Сайт полностью адаптирован для:
- Десктопов (1200px+)
- Планшетов (768px - 1199px)
- Мобильных устройств (до 767px)

## 🔧 Кастомизация

Вы можете легко изменить:
- **Цвета**: отредактируйте CSS переменные в `:root` в файле `styles.css`
- **Тексты**: измените содержимое в `index.html`
- **Градиенты**: замените значения `--gradient-1`, `--gradient-2` и т.д.
